Uso de herramientas de apoyo.

Durante el desarrollo del proyecto se utilizaron herramientas de la inteligencia artificial como apoyo para resolver dudas con la sintaxis de Java, mejorar la organización del código y comprender algunos conceptos de la programación orientada a objetos.

El diseño, las pruebas, la adaptación, la integración de las funciones y la lógica general del proyecto fueron desarrollados manualmente durante todo el proceso de programación. 

La herramienta utilizada fue ChatGPT (OpenAI), principalmente como apoyo educativo y de consulta.
